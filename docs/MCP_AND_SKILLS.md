# MCP and Skills

## MCP Config Files

- `.mcp.json`: local project MCP config

## Included MCP Servers

- `filesystem`: repository file operations
- `fetch`: fetch documentation and HTTP resources
- `shopify-dev-mcp`: Shopify developer platform utilities, schema validation, and live docs

## Setup

1. Ensure MCP server packages are available through `npx`.
2. Adjust absolute paths in `.mcp.json` if your repo path differs.

## Repo Skills

- `.agent/skills/ui-ux-pro-max/SKILL.md`
- `.agent/skills/shopify-theme/SKILL.md`

## When To Use `shopify-theme`

Use it for Shopify Theme custom section/block creation, liquid schema adjustments, styling with Tailwind CSS v4 in the theme context, and theme deployment commands.
